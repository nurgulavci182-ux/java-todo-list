# Java Görev Listesi

Java programlama dili kullanılarak geliştirilmiş basit bir yapılacaklar listesi uygulamasıdır.

## Özellikler

- Görevleri listeleme
- Görevleri önceliklerine göre otomatik sıralama
- Tamamlanan görevleri öncelik sıralamasının dışında tutma


## Kullanılan Teknolojiler

- Java
- Object-Oriented Programming (OOP)
- File Handling

## Proje Yapısı

- `Main.java`: Programın başlangıç noktası
- `Task.java`: Görev sınıfı
- `TaskManager.java`: Görev yönetimi

## Geliştirici

Bu proje Java öğrenme sürecinde geliştirilmiştir.
